# DREAM SLAYER — ภารกิจล่าฝัน

เกมพิกเซล 8-bit สำหรับตั้งเป้าหมายเตรียมสอบเข้า ม.4 โรงเรียนเตรียมอุดมศึกษา

ตัวละครจะเดินลุยไปทีละด่านตาม XP ที่สะสมจากการอ่านหนังสือจริง
ตั้งแต่ทุ่งหญ้าจนถึงประตูปราสาทชมพู รวม 8 ด่าน

## เล่นยังไง

1. เลือกวิชาแล้วกด START 25 หรือ START 50 — ต้องอ่านจนครบเวลาถึงจะได้ XP
2. เคลียร์เควสประจำวัน 3 ข้อ (สุ่มใหม่ทุกวัน แก้คลังเควสเองได้ที่ EDIT MISSIONS)
3. บันทึกคะแนนข้อสอบเก่าใน BOSS LOG
4. ตั้งรางวัลของตัวเองใน SHOP แล้วใช้ XP แลก

## ระบบ

- 9 ไอเทมปลดล็อกตามเลเวล ทุกชิ้นโผล่บนตัวละครจริง จบที่มงกุฎ LV20
- ถึงปราสาทเมื่อสะสมครบ 9,871 XP (ประมาณ 6 เดือนถ้าอ่านสม่ำเสมอ)
- ข้อมูลเก็บใน localStorage ของเบราว์เซอร์ สำรองไฟล์ได้ที่ OPTION > EXPORT

ไฟล์เดียวจบ ไม่ต้อง build ไม่มี dependency
